# Contributing

## Setup
1. Install Rust stable and `wasm32-unknown-unknown` target.
2. Install Stellar CLI.
3. Run `cargo test`.

## Branching
- `main` is protected.
- Create feature branches from `main`.
- Open PRs with test evidence.

## PR Requirements
- Include problem statement and approach.
- Add/adjust tests for behavior changes.
- Document storage/layout changes in `docs/`.
